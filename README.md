# 200-Day Moving Average Screener

시가총액 상위 N개 종목 각각에 200일 이동평균선 매수/매도 규칙을 백테스트하고,
현재 이평선 위(매수 상태)인 종목 중 백테스트 CAGR이 높은 순으로 상위 K개를 선별합니다.

`momentum_screener`(상대모멘텀 스크리너) 프로젝트와 별개의 독립 도구입니다.
추후 "상대모멘텀으로 1차 선별 → 이 도구로 200일선 2차 검증" 형태의 복합 분석으로 연동할 계획입니다.

## 로직

1. **유니버스 구성**: 국가별 시가총액 상위 N개 종목
2. **가격 데이터**: 기본 3년치(200일선 계산 + 백테스트에 충분한 기간) 일별 종가 배치 다운로드 (yfinance)
3. **종목별 200일선 상태전이 백테스트** (이전 Trailing Stop-Loss 프로젝트와 동일한 구조):
   ```
   보유 중: 종가가 200일선 아래로 이탈 -> 매도(현금 전환)
   현금 중: 종가가 200일선 위로 회복 -> 매수(보유 전환)
   ```
4. **현재 상태 판정**: 종가가 지금 200일선 위/아래인지, 이격도(%)는 얼마인지
5. **선별**: 기본적으로 "현재 매수 상태(이평선 위)"인 종목만 남기고, 백테스트 CAGR 높은 순 정렬 후 상위 K개 출력
   (체크박스로 이평선 아래 종목 포함 여부 전환 가능)

## 실행 방법

### Streamlit 웹앱 (권장)

1. 이 저장소를 GitHub에 push
2. [share.streamlit.io](https://share.streamlit.io) → GitHub 로그인 → New app
3. Main file path: `streamlit_app.py`

### 로컬 CLI

```bash
pip install -r requirements.txt
python ma_screener.py --country KR --n 100 --k 10
```

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--country` | KR 또는 US | 필수 |
| `--n` | 시가총액 상위 후보군 크기 | 100 |
| `--k` | 최종 선별 종목 수 | 10 |
| `--lookback-days` | 가격 데이터 조회 기간(일) | 1095(3년) |
| `--include-below-ma` | 이평선 아래 종목도 포함 | 미포함(기본) |

## 한계 / 참고사항

- 거래비용·슬리피지 미반영 (순수 로직 검증용)
- 200일선 상태전이 방식은 단순한 형태라 "휩쏘"(잦은 매매) 위험이 있음 — 밴드나 판단주기 완화 등 보완 필요할 수 있음
- 데이터 소스는 yfinance·네이버 금융 서비스 상태에 의존
